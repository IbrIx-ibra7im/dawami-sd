نظام متكامل واحترافي لإدارة وتسجيل حضور وغياب الطلاب بتقنيات التعرف الحيوي (البصمة الحيوية) والباركود الذكي، صُمم خصيصاً لخدمة الجامعات والمؤسسات التعليمية (**جامعة دنقلا - كلية علوم الحاسوب والتنمية البشرية**).

---

## 🌟 أبرز مميزات النظام

### 1. 🖐️ تسجيل الحضور بالبصمة الحيوية (Biometrics)
- تسجيل حضور فوري ومباشر دون الحاجة لتسجيل دخول مسبق (Kiosk Mode).
- مطابقة سريعة (1:N Identification) للتعرف التلقائي على الطالب المسجل من بصمته.
- دعم قراءة البصمة عبر أجهزة اللابتوب (Windows Hello / Touch ID) ومستشعرات USB الخارجية وقارئات ZKTeco.
- حفظ قوالب البصمة بتشفير آمن (Hash Templates) دون تخزين الصور الخام لحماية الخصوصية.
- منع تكرار تسجيل البصمة لأكثر من طالب ومنع تكرار الحضور في نفس المحاضرة أو اليوم.

### 2. 🪪 المسح السريع بالباركود والبطاقات الذكية (Barcode & QR)
- دعم قراءة الباركود والبطاقات الجامعية فورياً باستخدام أجهزة الباركود السلكية واللاسلكية (USB Barcode Guns) عبر استماع لوحة المفاتيح التلقائي.
- دعم مسح رمز الاستجابة السريعة (QR Code) المتولد لكل طالب.
- شاشة مزدوجة تفاعلية تجمع بين مستشعر البصمة ومسح الباركود في واجهة واحدة موحدة مع أنيميشن المسح الليزري.

### 3. 🛡️ حماية لوحة التحكم وصلاحيات الوصول
- فصل كامل بين **محطة تسجيل الحضور المباشرة** (لا تتطلب تسجيل دخول لتمكين الطلاب من إثبات الحضور بسلاسة) وبين **لوحة التحكم الإدارية**.
- دخول لوحة التحكم محمي بكلمة مرور إدارية معتمدة ونظام أدوار وصلاحيات (مدير النظام، مسجل، مشرف، موظف حضور).

### 4. ⚡ معمارية تخزين البيانات والعمل دون إنترنت (Offline-First)
- نظام تخزين فائق السرعة يعتمد على **Hive NoSQL** لضمان استجابة لحظية في تسجيل الحضور دون أي تأخير أو تجميد.
- قاعدة بيانات علائقية متوافقة مع **SQLite (sqflite_ffi)** لتوليد الاستعلامات والتقارير المتقدمة.
- محرك مزامنة ذكي مع خادم **Supabase** السحابي مع دعم العمل أوفلاين بنسبة 100%، وخاصية المزامنة والتسوية المحلية لتفادي انقطاع الإنترنت.
- إمكانية تصدير واستيراد حزم المزامنة والنسخ الاحتياطي عبر ملفات JSON المشفرة.

### 5. 📊 التقارير والإحصائيات وتصدير البيانات
- تصدير كشوفات وسجلات الحضور وبيانات الطلاب مباشرة إلى ملفات **Excel (.xlsx)** احترافية بنقرة زر واحدة.
- طباعة وتصدير تقارير رسمية وشهادات الحضور بصيغة **PDF**.
- إحصائيات بيانية دقيقة لنسب الحضور، الغياب، التأخير، وطرق التسجيل المستخدمة.

## 🛠️ التقنيات المستخدمة (Tech Stack)

| التقنية | الاستخدام |
|---------|-----------|
| **Flutter & Dart** | إطار العمل الرئيسي للتطبيق متعدد المنصات (Desktop, Web, Mobile) |
| **Provider** | إدارة الحالة (State Management) |
| **Hive & Hive Flutter** | التخزين المحلي السريع بدون قفل (Zero-lock NoSQL) |
| **SQLite (sqflite_ffi / web)** | قاعدة البيانات المحلية للتقارير والنسخ الاحتياطي |
| **Supabase Flutter** | المزامنة السحابية وقاعدة البيانات المركزية |
| **Local Auth** | واجهة التعامل مع مستشعرات البصمة والتحقق البيومتري |
| **Excel & Syncfusion PDF** | توليد وتصدير ملفات التقارير بجودة عالية |

## 🚀 طريقة التشغيل (Getting Started)

### المتطلبات المسبقة:
- تثبيت [Flutter SDK](https://docs.flutter.dev/get-started/install) (الإصدار 3.19 أو أحدث).
- متصفح Google Chrome (لتشغيل نسخة الويب) أو بيئة Windows Desktop.

### خطوات التثبيت:

1. **استنساخ المستودع (Clone Repository):**
   ```bash
   git clone https://github.com/IbrIx-ibra7im/dawami-sd.git
   cd dawami-sd
   ```

2. **تثبيت الحزم والمكتبات:**
   ```bash
   flutter pub get
   ```

3. **تشغيل الفحص الآلي والتأكد من سلامة الكود:**
   ```bash
   flutter analyze
   flutter test
   ```

4. **تشغيل التطبيق:**
   - **على متصفح Chrome (Web):**
     ```bash
     flutter run -d chrome
     ```
   - **على نظام Windows:**
     ```bash
     flutter run -d windows
     ```
